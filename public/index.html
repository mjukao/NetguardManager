สร้าง Bot ใหม่

ใช้ได้เฉพาะ a-z, 0-9, - เท่านั้น (2-31 ตัวอักษร)
แนะนำ port ว่างถัดไปให้อัตโนมัติ (แก้ไขได้)
เว้นว่างได้ ถ้ายังไม่มี tunnel — เพิ่มทีหลังได้
วิธีหา Token
  1. เปิด dash.cloudflare.com
  2. ไปที่ Zero Trust → Networks → Tunnels
  3. กด Create a tunnel → เลือก Cloudflared
  4. ตั้งชื่อ → Save
  5. เลือก Docker → copy token จากคำสั่งที่แสดง (ส่วนที่ต่อจาก --token)
  6. ตั้ง Public Hostname ชี้ไปที่ http://netguard-<ชื่อ bot>:3000
